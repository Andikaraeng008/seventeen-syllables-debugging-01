One haiku about debugging, in the 5-7-5 syllable shape — seventeen syllables, read in one breath.

```
Cursor blinks at three
a thousand log lines scroll past
just one wrong letter
```

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

`main.py` (Python 3.13, standard library only) writes the haiku to `/output/entry.txt`.
